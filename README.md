Konzolos Rajzoló

Indítás

A program futtatása kétféleképpen lehetséges:

1. Fejlesztői környezetből (pl. Visual Studio):
    Nyisd meg a megoldásfájlt (`.sln`) vagy a projektet (`.csproj`).
    Nyomd meg az **F5** billentyűt vagy kattints a **Start** gombra.

2. Parancssorból (.NET SDK szükséges):**
    Lépj be a projekt mappájába a terminálban, majd futtasd a következő parancsot: dotnet run


Megjegyzés: A helyes megjelenéshez állítsd a konzolablak méretét legalább 90 karakter szélesre és 26 sor magasra.

Vezérlés

Rajzoló mód

Nyílbillentyűk (↑, ↓, ←, →): A kurzor mozgatása a rajzlapon. Letett eszközzel rajzol is.

Szóköz (Space): Eszköz váltása (felemelve / letéve). Letételkor az aktuális cellába is rajzol.

F1 – F3: X alakzat nyomdázása (3×3, 5×5, 7×7).

F4 – F6: Kereszt (+) nyomdázása (3×3, 5×5, 7×7).

F7 – F9: Négyzetkeret nyomdázása (3×3, 5×5, 7×7).

F10 – F12: Rombuszkeret nyomdázása (3×3, 5×5, 7×7).

M: Belépés a menübe.

X: Kilépés a programból.

Menü mód

Fel / Le nyilak (↑, ↓): Lépegetés a menüpontok között.

Enter: Kiválasztott menüpont megnyitása / végrehajtása.

Esc: Visszalépés a rajzhoz (vagy az almenükből való kilépés).
